# Practice character assets

Drop transparent GIF files into this directory to replace the built-in CSS
fallbacks. The tutorial loads these names automatically:

- `shu-idle.gif`
- `shu-point.gif`
- `shu-explain.gif`
- `shu-surprise.gif`
- `shu-cheer.gif`
- `shu-gone.gif`
- `miu-idle.gif`
- `miu-ready.gif`
- `miu-thinking.gif`
- `miu-accept.gif`
- `miu-reject.gif`
- `miu-panic.gif`
- `miu-gone.gif`
- `miu-shock.gif`
- `miu-lose.gif`

Keep the character centered on a transparent canvas. A square canvas is the
easiest drop-in shape. When reduced motion is enabled, the tutorial hides the
animated asset and uses the still CSS fallback.
